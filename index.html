Installation instructions

Choose the section that matches your situation.

Already played on this server?

Close the game and launcher

Make sure The Mighty Quest for Epic Loot and its launcher are fully closed.

Open the Steam install folder

In Steam, right-click The Mighty Quest For Epic Loot, then choose Manage → Browse local files. Open the Launcher folder.

Replace the settings file

Download PublicLauncherSettings.json above and place it in the Launcher folder. Choose Replace the file in the destination when Windows asks.

Start the game through Steam

Launch the game from Steam. Your Steam ID should log you in automatically. Do not enter a password into an unexpected login form.

Maintenance screen? Check that the new settings file is still in the Launcher folder. A Steam update or “Verify integrity of game files” can restore the old file. Try again with your VPN off. If you see a name/password form instead of automatic Steam login, stop and contact the server maintainer.

Installing for the first time?

Install the original game

Install The Mighty Quest For Epic Loot from Steam, then use Manage → Browse local files to open its installation folder.

Install the launcher executable

Put PublicLauncher.exe inside the game's Launcher folder.

Install the patch script

Put steam-launcher-patch.cmd in the main game folder, beside the game's other top-level files. Use the complete file from this website; do not recreate it from a partial code snippet.

Apply the launcher patch

Run steam-launcher-patch.cmd from the game folder, then make sure the current PublicLauncherSettings.json is in the Launcher folder. Start the game from Steam.

Launcher executable and settings file go here:
C:\Program Files (x86)\Steam\steamapps\common\The Mighty Quest For Epic Loot\Launcher
The patch script goes here:
C:\Program Files (x86)\Steam\steamapps\common\The Mighty Quest For Epic Loot

Steam may be installed in a different library location on your PC. The folders above are the default example.

Common questions

Steam replaced my settings file. What should I do?

Download the current settings file from this page and replace the copy in the game's Launcher folder again. Steam updates and file verification can restore the original launcher settings.

The game asks me for a username and password. Should I sign in?

No. The expected flow is automatic login using your Steam ID. Close the game and contact the server maintainer rather than entering credentials into an unexpected form.

Windows warns me about a downloaded file.

Do not bypass security warnings just because an instruction says to. Verify that you are on the official HTTPS domain and check the file's published SHA-256 hash. If no hash is published, ask the maintainer to provide one before running the file.

Is this an official Ubisoft service?

No. This is a community-run revival project and is not affiliated with or endorsed by Ubisoft.

Connection note for players: The current launcher settings supplied for this server still use HTTP for some launcher and patcher endpoints. This website being HTTPS does not encrypt those separate connections. The server operator should move all launcher and patcher endpoints behind HTTPS before describing the complete update process as end-to-end secure.
