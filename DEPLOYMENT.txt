IMPORTANT SECURITY CHECKLIST
1. Serve the website only over HTTPS and set the canonical URL to https://www.themightyquest-reborn.com/.
2. Keep the EXE and CMD downloads on this domain. Do not use expiring Discord CDN URLs or user-submitted mirrors as permanent website links.
3. Publish SHA-256 hashes for every release and update them whenever a file changes. On Windows, calculate them with:

   Get-FileHash .\PublicLauncher.exe -Algorithm SHA256
   Get-FileHash .\steam-launcher-patch.cmd -Algorithm SHA256

4. Consider Authenticode-signing PublicLauncher.exe. A checksum detects a changed file; a trusted digital signature can also identify the publisher.
5. Restrict write access to the hosting account/repository and enable two-factor authentication. A static page cannot stop someone from copying its URL or cloning its appearance; hashes, signed binaries, protected deployment credentials, and a clearly advertised canonical domain help users detect tampering.
6. Do not tell players to disable Windows Defender, SmartScreen, or other security software.

SERVER TRANSPORT WARNING
The supplied configuration uses HTTP for LauncherWebSiteUrl, PatcherServiceUrl, BackgroundImageUrl, and MaintenanceModeVerificationUrl. GameServerUrl uses HTTPS. The website's HTTPS certificate does not protect those separate HTTP requests. Before claiming end-to-end secure updates, put the launcher and patcher endpoints behind HTTPS with a valid certificate and update the settings file to use those HTTPS hostnames.
